# Текущий контроль. Задание 6: класс «Время» (Time)

Создайте класс, содержащий часы, минуты и секунды. Реализуйте методы добавления к текущему времени определенного количества секунд или минут с корректным переполнением (например, если секунд стало 65, минуты увеличиваются на 1, а секунд остается 5).

```text
Начальное время
Часы –> 23
Минуты –> 59
Секунды –> 0
Время: 23:59:00
-----------------------------
1 – Добавить секунды
2 – Добавить минуты
0 – Выход
Ваш выбор –> 1
Сколько секунд –> 65
Время: 00:00:05
```

## Уточнения

- Часы идут по кругу от 0 до 23: после 23:59:59 наступает 00:00:00.
- Можно добавлять и отрицательное количество: время отматывается назад с тем же переносом.
- Программа проверяет ввод: нечисловые данные и время вне диапазона дают сообщение об ошибке.
