# Задание: линейные программы и ветвление

Для каждой задачи написать программу. Ниже приведён рекомендуемый вид экрана, данные вводит пользователь после `->`.

## Задача 1. Доход по вкладу

Написать программу вычисления дохода по вкладу. Сумма, процентная ставка (% годовых) и срок вклада (в месяцах) задаются во время работы программы.

```text
Вычисление дохода по вкладу
Введите исходные данные:
Сумма вклада (руб.) -> 25000
Срок вклада (месяцев) -> 6
Процентная ставка (годовых) -> 10
-------------------------------------
Доход: 1250.00 руб.
Сумма по окончании срока вклада: 26250.00 руб.
```

## Задача 2. Минуты в часы и минуты

Написать программу пересчёта величины временного интервала, заданного в минутах, в величину, выраженную в часах и минутах.

```text
Введите временной интервал (в минутах) -> 150
150 минут - это 2 ч. 30 мин.
```

## Задача 3. Денежный формат

Написать программу, которая преобразует введённое с клавиатуры дробное число в денежный формат. Например, число 12,5 должно быть преобразовано к виду 12 руб. 50 коп.

```text
Преобразование числа в денежный формат
Введите дробное число -> 23.6
23.6 руб. - это 23 руб. 60 коп.
```

## Задача 4. Фунты в килограммы

Написать программу пересчёта веса из фунтов в килограммы (1 фунт — 405,9 г).

```text
Пересчет веса из фунтов в килограммы
Введите вес в фунтах и нажмите Enter -> 3.5
3.5 фунт(а/ов) - это 1 кг 420 гр.
```

## Задача 5. Сопротивление цепи

Написать программу вычисления сопротивления электрической цепи, состоящей из двух сопротивлений, которые могут быть соединены последовательно или параллельно.

```text
Вычисление сопротивления электрической цепи
Введите исходные данные:
Величина первого сопротивления (Ом) -> 15
Величина второго сопротивления (Ом) -> 27.3
Тип соединения (1-последовательное, 2-параллельное) -> 2
Сопротивление цепи: 9.68 Ом
```

## Задача 6. Вклад: ставка зависит от суммы (2 варианта)

Написать программу вычисления дохода по вкладу. Исходные данные: сумма и срок вклада. Если сумма меньше 5000 руб., то процентная ставка 10%, если больше, то 13%.

```text
Доход
Сумма, руб. -> 10000
Срок вклада, мес. -> 12
----------------------------
Сумма: 10000.00 руб.
Срок вклада: 12 мес.
Процент годовой: 13
Доход: 1300.00 руб.
Сумма в конце срока вклада: 11300.00 руб.
```

## Задача 7. Вклад: ставка зависит от суммы (3 варианта)

Написать программу вычисления дохода по вкладу. Исходные данные: сумма и срок вклада. Если сумма меньше 5000 руб., то процентная ставка 9%, если больше 5000 руб., но меньше 10 000 руб., то 11%, а если больше 10 000, то 13%.

```text
Доход
Сумма, руб. -> 15000
Срок вклада, мес. -> 6
------------------------------------------------------
Сумма: 15000.00 руб.
Срок вклада: 6 мес.
Процент годовой: 13.00
Доход: 975.00 руб.
Сумма в конце срока вклада: 15975.00 руб.
```

## Задача 8. Печать фотографий

Написать программу вычисления стоимости печати фотографий. Формат фотографий 9×12 или 10×15. Если количество фотографий больше 10, то заказчику предоставляется скидка 5%.

```text
Фотографии
Формат (1 – 9х12; 2 – 10х15) -> 2
Количество, шт. -> 15
----------------------------
Цена: 3.20 руб.
Количество: 15 шт.
Сумма: 48.00 руб.
Скидка: 2.40 руб.
К оплате: 45.60 руб.
```

## Задача 9. Ток в электрической цепи

Написать программу, которая вычисляет величину тока, потребляемого электроприбором (I = P/U, где I — ток, А; P — мощность, Вт; U — напряжение, В). Программа должна проверять правильность введённых данных и, если они неверные (делитель равен нулю), выводить сообщение об ошибке.

```text
Ток в электрической цепи
Мощность, Вт -> 60
Напряжение, В -> 0
Ошибка! Напряжение не должно быть равно нулю
```

## Задача 10. Площадь кольца

Написать программу вычисления площади кольца. Программа должна проверять правильность исходных данных.

```text
Введите исходные данные:
радиус кольца (см) -> 3.5
радиус отверстия (см) -> 7
Ошибка! Радиус отверстия больше радиуса кольца
```

## Задача 11. Минуты и секунды в секунды

Написать программу, которая переводит время из минут и секунд в секунды. Программа должна проверять правильность введённых данных и в случае, если данные неверные, выводить соответствующее сообщение.

```text
Введите время (минут.секунд) -> 2.90
Ошибка! Число секунд не может быть больше 60
Для завершения нажмите Enter
```

## Задача 12. Високосный год

Написать программу, которая проверяет, является ли год високосным.

```text
Введите год, например 2000,
и нажмите Enter -> 2001
2001 год – не високосный
Для завершения нажмите Enter
```

## Задача 13. Квадратное уравнение

Написать программу решения квадратного уравнения. Программа должна проверять правильность исходных данных и в случае, если коэффициент при второй степени неизвестного равен нулю, выводить соответствующее сообщение.

```text
Решение квадратного уравнения
Введите в одной строке коэффициенты и нажмите Enter -> 12 27 -10
Корни уравнения: x1= 0.324 x2= -2.574
```

## Задача 14. Скидка 10%

Написать программу вычисления стоимости покупки с учётом скидки. Скидка в 10% предоставляется, если сумма покупки больше 1000 руб.

```text
Вычисление стоимости покупки с учетом скидки
Сумма покупки -> 1200
Вам предоставляется скидка 10%
Сумма покупки с учетом скидки: 1080.00 руб.
```

## Задача 15. Скидка 3% или 5%

Написать программу вычисления стоимости покупки с учётом скидки. Скидка в 3% предоставляется, если сумма покупки больше 500 руб., в 5% — если сумма больше 1000 руб.

```text
Вычисление стоимости покупки с учетом скидки
Введите сумму покупки и нажмите Enter -> 640
Вам предоставляется скидка 3%
Сумма с учетом скидки: 620.80 руб.
```

## Отличия от исходного файла

Условие и примеры выше поправлены там, где исходный файл расходится сам с собой или не даёт ответа.

- **Задача 8.** Цена дана только для формата 10×15 (3.20 руб.). Для 9×12 принято 2.50 руб.
- **Задача 6.** Для суммы ровно 5000 руб. ставка не задана, принято 13%.
- **Задача 7.** Для сумм ровно 5000 и 10 000 руб. ставка не задана, принято 11% и 13%.
- **Задача 10.** Равные радиусы считаются ошибкой: кольца в этом случае нет.
- **Задача 11.** Секунды, равные 60, не считаются ошибкой: в условии ошибка только при значении больше 60.
- **Задача 12.** В исходном примере введён 2001 год, а в ответе указан 2000. Здесь в ответе 2001.
- **Задача 13.** В исходном примере корни неверные (x1 = -25.551, x2 = -28.449). Здесь верные значения.

Сверх условия все программы проверяют ввод: нечисловые данные, отрицательные и слишком большие значения дают сообщение об ошибке. Дробную часть числа нужно вводить через точку, как в примерах.
