# Задание: случайные числа, циклы и массивы

Для каждой задачи написать программу. Ниже приведён рекомендуемый вид экрана, данные вводит пользователь после `->` или `>`. В задачах 1, 2 и 9 числа случайные, поэтому при каждом запуске они другие.

## Задача 1. Десять случайных чисел

Написать программу, которая генерирует последовательность из 10 случайных чисел (в диапазоне от 1 до 10), выводит эти числа на экран и вычисляет их среднее арифметическое.

```text
Случайные числа
1
3
4
2
7
4
9
6
2
1
Сред. арифм.: 3.90
```

## Задача 2. Три случайные последовательности

Написать программу, которая генерирует три последовательности из десяти случайных чисел (в диапазоне от 1 до 10). Для каждой последовательности программа должна вычислить среднее арифметическое.

```text
Случайные числа
6 10 4 2 5 8 1 7 7 3 сред. арифм.: 5.30
10 3 6 1 10 1 3 8 7 6 сред. арифм.: 5.50
5 2 2 5 4 2 2 1 6 10 сред. арифм.: 3.90
```

## Задача 3. Стоимость яблок

Написать программу, которая выводит на экран таблицу стоимости, например, яблок в диапазоне от 100 г до 1 кг с шагом 100 г.

```text
Введите цену одного килограмма и нажмите Enter
(копейки от рублей отделяйте точкой)
-> 16.50
-------------------------
Вес, гр.  Стоимость, руб.
-------------------------
     100             1.65
     200             3.30
...
    1000            16.50
-------------------------
```

## Задача 4. Цельсий и Фаренгейт

Написать программу, которая выводит на экран таблицу соответствия температуры в градусах Цельсия и Фаренгейта (F = 9/5·C + 32). Диапазон изменения температуры в градусах Цельсия и шаг должны вводиться во время работы программы.

```text
t1 –> 0
t2 –> 10
dt –> 1
----------------
    C         F
----------------
  0.00     32.00
  1.00     33.80
...
 10.00     50.00
```

## Задача 5. Сумма и среднее до нуля

Написать программу, вычисляющую сумму и среднее арифметическое последовательности положительных чисел, которые вводятся с клавиатуры.

```text
Вычисление среднего арифметического последовательности положительных чисел.
Вводите после стрелки числа. Для завершения ввода введите ноль.
> 45
> 23
> 15
> 0
Введено чисел: 3
Сумма чисел: 83
Среднее арифметическое: 27.67
```

## Задача 6. Максимальное число

Написать программу, которая определяет максимальное число из введённой с клавиатуры последовательности положительных чисел (длина последовательности не ограничена).

```text
Определение максимального числа из последовательности положительных чисел.
Вводите числа после стрелки. Для завершения ввода введите ноль.
> 56
> 75
> 43
> 0
Максимальное число: 75
```

## Задача 7. Минимальное число

Написать программу, которая определяет минимальное число во введённой с клавиатуры последовательности положительных чисел (длина последовательности не ограничена).

```text
Определение минимального числа в последовательности положительных чисел.
Вводите после стрелки числа. Для завершения ввода введите ноль.
> 12
> 75
> 10
> 9
> 23
> 0
Минимальное число: 9
```

## Задача 8. Простое число

Написать программу, которая проверяет, является ли введённое пользователем целое число простым (простым называется число, которое делится только на единицу и на само себя).

```text
Введите целое число и нажмите Enter
> 17
17 - простое число.
```

## Задача 9. Угадай число

Написать программу, которая «задумывает» число в диапазоне от 1 до 10 и предлагает пользователю угадать его за пять попыток.

```text
Игра "Угадай число".
Компьютер "задумал" число от 1 до 10.
Угадайте его за пять попыток.
Введите число и нажмите Enter
> 5
Нет.
-> 3
Вы выиграли! Поздравляю!
```

## Задача 10. Число Пи

Написать программу, которая вычисляет число «Пи» с заданной пользователем точностью. Для вычисления числа π воспользуйтесь тем, что значение частичной суммы ряда 1 – 1/3 + 1/5 – 1/7 + 1/9 ..., при суммировании достаточно большого количества членов, приближается к π/4.

```text
Задайте точность вычисления Пи -> 0.001
Значение числа Пи с точностью 0.001000 равно 3.143589
Просуммировано 501 членов ряда.
```

## Задача 11. Массив из семи чисел

Написать программу, которая записывает введённые с клавиатуры данные в одномерный массив целого типа, состоящий из семи элементов. Перед вводом каждого элемента должна выводиться подсказка с номером элемента. После ввода последнего элемента программа должна вывести введённый массив и вычислить среднее арифметическое его элементов.

```text
Ввод массива целых чисел
После ввода каждого числа нажмите Enter
a[0] -> 10
a[1] -> 16
a[2] -> 14
a[3] -> 5
a[4] -> 10
a[5] -> 22
a[6] -> 22
Массив: 10 16 14 5 10 22 22
Среднее арифметическое: 14.14
```

## Задача 12. Ненулевые элементы

Написать программу, которая вводит с клавиатуры данные в одномерный массив дробного типа, состоящий из пяти элементов, после чего выводит количество ненулевых элементов. Перед вводом каждого элемента должна выводиться подсказка с номером элемента.

```text
Ввод массива дробных чисел
После ввода каждого числа нажмите Enter
a[1] -> 12
a[2] -> 0
a[3] -> 3
a[4] -> -1
a[5] -> 0
------------------------
Ненулевых элементов: 3
```

## Задача 13. Минимальный элемент массива

Написать программу, которая выводит минимальный элемент введённого с клавиатуры массива целых чисел.

```text
Поиск минимального элемента массива
Введите в одной строке 5 целых чисел и нажмите Enter
-> 23 0 45 -5 12
Минимальный элемент массива: -5
```

## Задача 14. Среднее ненулевых элементов

Написать программу, которая вычисляет среднее арифметическое ненулевых элементов введённого с клавиатуры массива целых чисел.

```text
Введите элементы массива (10 целых чисел в одной строке) и нажмите Enter
-> 23 0 45 -5 12 0 -2 30 0 64
-------------------------------
Сумма элементов массива: 167
Количество ненулевых элементов: 7
Среднее арифметическое ненулевых элементов: 23.86
```

## Отличия от исходного файла

Условие и примеры выше поправлены там, где исходный файл расходится сам с собой или не даёт ответа.

- **Задача 3.** В исходном примере таблица слиплась в одну строку. Здесь она выведена в две колонки, вес и стоимость. Стоимость округляется до копеек.
- **Задача 4.** В исходной формуле дробь перевёрнута (5/9). Таблица из условия соответствует формуле F = 9/5·C + 32, она и использована.
- **Задачи 5–7.** Условие не говорит, что делать с отрицательным числом. Программа сообщает об ошибке и завершается. Если сразу введён ноль, выводится «Не введено ни одного числа».
- **Задача 6.** В исходном примере максимальным назван 7, хотя введены 56, 75 и 43. Максимальное число здесь 75.
- **Задача 8.** Числа меньше 2 (ноль, единица, отрицательные) считаются не простыми. Проверяются числа до 10¹² по модулю.
- **Задача 9.** Если ввод не число или число не из диапазона 1–10, выводится ошибка, а попытка не тратится. После пяти неверных ответов программа сообщает, какое число было задумано.
- **Задача 10.** В исходном примере указано 502 члена ряда. Последний прибавленный член 1/1001 меньше 0.001, это 501-й член ряда, и сумма 3.143589 получается ровно при 501 члене. Точность нужно задавать от 0.000001 до 1: при меньшей точности вычисление идёт слишком долго.
- **Задача 11.** В исходном примере среднее 14.00. Сумма элементов 99, среднее 99 / 7 = 14.14.
- **Задача 12.** В исходном примере заголовок «Ввод массива целых чисел», хотя массив дробный. Здесь «Ввод массива дробных чисел».
- **Задача 13.** Нужно ввести ровно 5 целых чисел, иначе выводится ошибка.
- **Задача 14.** В исходном примере сумма элементов 184. Сумма введённых чисел равна 167, и среднее 23.86 = 167 / 7 считается именно от неё. Если все элементы нулевые, выводится «Ненулевых элементов нет».

Сверх условия все программы проверяют ввод: нечисловые данные, недопустимые и слишком большие значения дают сообщение об ошибке. Целые числа в массивах ограничены 10⁹ по модулю. Дробную часть числа нужно вводить через точку, как в примерах.
