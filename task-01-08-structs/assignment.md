# Задание: описание объектов структурами

Для каждого объекта нужно описать структуру с перечисленными полями, заполнить несколько записей и вывести те, что подходят под условие. Пример оформления, решение задачи 8 на C++, лежит в [examples.docx](materials/examples.docx).

## Задача 1. Футболист

Фамилия, имя, отчество, пол, национальность, рост, вес, дата рождения (год, месяц, число), номер телефона, название команды, номер в команде, амплуа, результативность (количество голов), количество игр.

**Вывести:** футболистов, которые провели за свою команду больше 50 матчей.

## Задача 2. Студент

Фамилия, имя, отчество, пол, рост, вес, дата рождения (год, месяц, число), домашний адрес (почтовый индекс, страна, область, район, город, улица, дом, квартира).

**Вывести:** самого молодого студента.

## Задача 3. Международная компания

Название, интернет-сайт, адрес главного офиса (почтовый индекс, страна, область, район, город, улица, дом, квартира), продолжительность пребывания на мировом рынке, количество сотрудников, количество филиалов в Европе.

**Вывести:** компании, в которых больше 10 000 сотрудников.

## Задача 4. Зоопарк

Название животного, количество животных этого вида, адрес зоопарка (почтовый индекс, страна, область, район, город, улица, дом, квартира), общее количество животных, количество работников.

**Вывести:** зоопарки, в которых есть уссурийские тигры.

## Задача 5. Мультфильм

Название, режиссёр (фамилия, имя), год выхода, страна, стоимость, доход, прибыль.

**Вывести:** мультфильмы компании «Walt Disney».

## Задача 6. Баскетболист

Фамилия, имя, отчество, пол, национальность, рост, вес, дата рождения (год, месяц, число), номер телефона, название команды, номер в команде, амплуа, результативность (количество очков), количество игр.

**Вывести:** баскетболистов, которые набрали за свою команду больше 150 очков.

## Задача 7. Область

Название области, областной центр, население, площадь территории, губернатор.

**Вывести:** области с населением меньше 1 млн жителей.

## Задача 8. Мотоцикл

Марка, цвет, серийный номер, регистрационный номер, год выпуска, год техосмотра, цена.

**Вывести:** мотоциклы марки «HarleyDavidson».

## Отличия от исходного файла

- **Задача 2.** По сравнению с заданием [task-01-08-records](../task-01-08-records/assignment.md) вместо манекенщицы теперь студент, поля «национальность» у него нет. Самый молодой тот, у кого дата рождения позже: сравниваются год, потом месяц, потом число.
- **Задача 4.** В исходнике «количество вида». Здесь у зоопарка есть название и список видов, у каждого вида своё количество. Тигры считаются найденными, если их больше нуля.
- **Задача 5.** В списке полей нет компании, а вывести нужно мультфильмы «Walt Disney». Добавлено поле «студия». Прибыль не хранится отдельно, а считается как доход минус стоимость. Суммы указаны в миллионах долларов.
- **Задача 6.** В исходнике «которых забросили … больше 150 очей», здесь «которые набрали больше 150 очков».
- Данные в программах придуманы для примера. В каждом наборе есть записи, которые под условие не подходят. Если подходящих нет, программа пишет «Подходящих записей нет».
