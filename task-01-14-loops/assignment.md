# Задание: выбор, циклы и таблицы

Для каждой задачи написать программу. Ниже приведён рекомендуемый вид экрана, данные вводит пользователь после `->`.

## Задача 1. Печать фотографий

Написать программу, которая позволяет посчитать стоимость печати фотографий. Исходные данные: размер фотографий (9×12, 10×15 или 18×24) и их количество. Если заказанных фотографий больше 10, заказчику должна предоставляться скидка 10%.

```text
Фото
Размер:
1 – 9х12
2 – 10х15
3 – 18х24
Ваш выбор –> 1
Количество –> 12
-----------------------------
Цена: 3.50 руб.
Количество: 12 шт.
Сумма: 42.00 руб.
Скидка: 4.20 руб.
К оплате: 37.80 руб.
```

## Задача 2. Заправка автомобиля

Написать программу, которая позволяет посчитать стоимость заправки автомобиля. Исходные данные: тип топлива (бензин 92, 95, 98 или дизельное топливо) и количество литров.

```text
Бензин
Марка бензина:
1 – 92
2 – 95
3 – 98
4 – DT
Ваш выбор –> 2
Литров –> 25
-----------------------------
Цена за литр: 20.30 руб.
Литров: 25
К оплате: 507.50 руб.
```

## Задача 3. Таблица квадратов

Написать программу, которая выводит таблицу квадратов первых десяти целых положительных чисел.

```text
Таблица квадратов
--------------
Число Квадрат
--------------

  2        4
...

--------------
```

## Задача 5. Скорость свободного падения

Написать программу, которая выводит таблицу скорости (через каждые 0,5 с) свободно падающего тела (v = g·t, где g = 9,8 м/с² — ускорение свободного падения).

```text
-----------------------
Время, с Скорость, м/с
-----------------------
  0.0        0.00
  0.5        4.90
...
  3.0       29.40
-----------------------
```

## Задача 6. Платежи по кредиту

Написать программу, которая выводит таблицу ежемесячных платежей по кредиту. Исходные данные: сумма кредита, срок и процентная ставка. Кредит возвращается ежемесячно равными долями, проценты начисляются ежемесячно на величину долга.

```text
Сумма кредита (руб.) -> 150000
Срок (мес.) -> 12
Процентная ставка (годовых) -> 14
---------------------------------------
           Долг     Процент      Платеж
---------------------------------------
  1   150000.00     1750.00    14250.00
  2   137500.00     1604.17    14104.17
...
 12    12500.00      145.83    12645.83
---------------------------------------
Всего процентов: 11375.00
```

## Задача 7. Цельсий и Фаренгейт

Написать программу, которая выводит на экран таблицу соответствия температуры в градусах Цельсия и Фаренгейта (F = 9/5·C + 32). Диапазон изменения температуры в градусах Цельсия и шаг должны вводиться во время работы программы.

```text
t1 –> 0
t2 –> 10
dt –> 1
----------------
    C         F
----------------
  0.00     32.00
  1.00     33.80
...
 10.00     50.00
```

## Задача 8. Сумма первых n чисел

Написать программу, которая вычисляет сумму первых n положительных целых чисел. Количество суммируемых чисел должно вводиться во время работы программы.

```text
Сумма положительных чисел
Введите количество суммируемых чисел -> 20
Сумма первых 20 положительных чисел равна 210
```

## Задача 9. Сумма первых n четных чисел

Написать программу, которая вычисляет сумму первых n целых положительных чётных чисел. Количество суммируемых чисел должно вводиться во время работы программы.

```text
Вычисление суммы четных положительных чисел
Введите количество суммируемых чисел и нажмите Enter
-> 12
Сумма первых 12 положительных четных чисел равна 156
```

## Задача 10. Сумма ряда 1, 3, 5, 7

Написать программу, которая вычисляет сумму первых n членов ряда: 1, 3, 5, 7 ... Количество суммируемых членов ряда задаётся во время работы программы.

```text
Вычисление частичной суммы ряда: 1,3,5,7, ...
Введите количество суммируемых членов ряда -> 15
Сумма первых 15 членов ряда равна 225
```

Таблица степеней двойки

## Задача 12. Факториал

Написать программу, которая вычисляет факториал введённого с клавиатуры числа. Факториалом числа n называется произведение целых чисел от 1 до n. Например, факториал 1 равен 1, факториал 8 — 40 320.

```text
Вычисление факториала
Введите число, факториал которого надо вычислить
-> 7
Факториал 7 равен 5040
```

## Задача 13. Среднее арифметическое пяти чисел

Написать программу, которая вводит с клавиатуры пять дробных чисел и вычисляет их среднее арифметическое.

```text
Среднее арифметическое последовательности дробных чисел.
После ввода каждого числа нажимайте Enter
-> 5.4
-> 7.8
-> 3.0
-> 1.5
-> 2.3
Среднее арифметическое введенной последовательности: 4.00
Для завершения нажмите Enter
```

## Задача 14. Обработка последовательности

Написать программу, которая вычисляет среднее арифметическое последовательности дробных чисел, вводимых с клавиатуры. После ввода последнего числа программа должна вывести минимальное и максимальное числа последовательности. Количество чисел последовательности должно задаваться во время работы программы.

```text
Обработка последовательности дробных чисел.
Введите количество чисел последовательности -> 5
Вводите последовательность. После ввода каждого числа нажимайте Enter
-> 5.4
-> 7.8
-> 3.0
-> 1.5
-> 2.3
Количество чисел: 5
Среднее арифметическое: 4.00
Минимальное число: 1.5
Максимальное число: 7.8
Для завершения нажмите Enter
```

## Отличия от исходного файла

Условие и примеры выше поправлены там, где исходный файл расходится сам с собой или не даёт ответа.

- **Задача 1.** Цена дана только для 9×12 (3.50 руб.). Для 10×15 и 18×24 взяты цены из присланного образца: 5.00 и 10.00 руб.
- **Задача 2.** В примере цена 50.30 руб. не сходится с итогом: 507.50 руб. за 25 литров дают 20.30 руб. Здесь цена 20.30 руб. Цены остальных марок в условии нет, приняты 19.50 (92), 22.10 (98) и 18.70 (DT).
- **Задача 6.** В примере нет строки с суммой кредита. Сумма 150000 восстановлена по таблице.
- **Задача 7.** В исходной формуле дробь перевёрнута (5/9). Таблица из условия соответствует формуле F = 9/5·C + 32, она и использована.
- **Задача 10.** В исходном примере указана сумма 330. Сумма первых 15 нечётных чисел равна 225.
- **Задача 12.** Факториал считается для чисел от 0 до 20: 0! = 1 по определению, а 21! не помещается в `long long`.

Сверх условия все программы проверяют ввод: нечисловые данные, отрицательные и слишком большие значения дают сообщение об ошибке. Дробную часть числа нужно вводить через точку, как в примерах.
